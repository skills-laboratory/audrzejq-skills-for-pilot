# Boeing 737 descent and arrival preparation

1. Read actual altitude, height AGL, IAS, ground speed, position, heading, FMA and selected targets. Confirm the current automation is maintaining a safe flight path. Load `737-checklist` and the live descent section; do not perform earlier ground procedures in flight.
2. Read the scenario walkthrough if provided, selected approach chart, descent/approach procedures, landing continuation and go-around instructions with `read_docs`. Keep runway identity, threshold elevation, frequency/ident, inbound course, distance reference, intercept altitude, minimums and missed-approach track/altitude together. Discover required controls before final approach, not during recovery.
3. Estimate time available from runway-relative distance and ground speed; flight continues during tool calls and reasoning. Prepare radios, altimeter, minimums, autobrake, signs and applicable lights early, verifying each action. Recheck position between preparation tasks. If preparation consumes the intercept distance, discontinue the approach using the documented safe procedure rather than flying past the airport while troubleshooting.
4. Set and verify the landing pressurization altitude and perform annunciator recall as prescribed. Record completed descent and approach items independently with `737-checklist`; an unavailable FMC entry must not stall the rest of the preparation.
5. Read APPROACH REF and verify gross weight, planned landing flaps and their VREF, then the applicable approach-speed correction. No active FMC route is required for a raw-data ILS; do not rebuild POS INIT or a route merely to attempt an approach. Scratchpad text is not an accepted selection. If an entry fails, check the documented page/key mapping and read the field back; after two unchanged attempts, report the limitation and stop retrying. Use an alternative weight-based speed source only if the operating documentation authorizes it; never invent a fixed landing speed. Without a supported safe speed, use the documented missed approach or safe holding procedure instead of descending to land.
6. Set the current local altimeter setting with the prescribed datum. Select the chart's intercept altitude consistent with terrain and clearance, and descend with a documented mode and safe configuration speed. Read actual FMA, selected targets and flight path after mode activation: V/S may synchronize to the current vertical speed. Verify the sign and magnitude again after setting it, including the setter's `detail`.
7. Cross-check the vertical plan using the chart's distance reference. A 3° final path rises approximately 320 ft per NM above threshold elevation; this is only a geometry check, not clearance to descend. Station DME is not automatically distance to the threshold. Arrange to intercept from below without violating charted altitudes; do not chase the glide slope from above close to the runway.
8. Load `737-approach` before intercept. If an altitude capture is required, use `737-altitude-hold` and verify actual acquisition/hold. A selected higher altitude does not stop a negative V/S command or establish a climb.
