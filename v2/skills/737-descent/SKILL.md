# Boeing 737 descent and approach preparation

- Read actual altitude, IAS, vertical speed, configuration, FMA, and distance to the approach. Preserve functioning automation while preparing; an ALT HOLD label or selected altitude does not prove level flight at that target. Interleave preparation with flight-path reads and correct drift before secondary tasks.
- Read the selected approach chart, live descent/approach checklists, landing continuation, and missed approach before intercept. Identify runway, ILS frequency/identifier, magnetic course, distance source, segment altitudes, minima datum, and missed-approach track/altitude. Different DME stations and threshold distance are not interchangeable; obtain the chart's required reference rather than assuming the ILS DME matches it.
- Set local QNH with the correct pressure units and verify the required altimeters and pressure-reference modes. Set pressurization landing altitude from the destination elevation, not the decision height; perform the prescribed annunciator recall and resolve actual warnings.
- For BARO minimums, enter the published DA/MDA in feet AMSL, not the parenthesized height above threshold. If only a height is supplied, use its stated datum elevation to obtain the altitude and cross-check it against threshold elevation. Use RADIO minimums only when the procedure authorizes them; simulator height above terrain is not automatically height above the runway. Read back both selector mode and value.
- Obtain landing weight and units from aircraft readings and the CDU instructions. Convert to the page's required units before entry; clear and verify the scratchpad is empty before replacing text, then verify the accepted weight and selected landing flap/VREF field. Generated VREF choices or scratchpad text alone do not prove selection. Set the weight/configuration-dependent approach speed with its prescribed correction and verify MCP speed and actual IAS.
- Set required passenger signs, lights, navigation receivers/courses, and autobrake; verify identifiers and decoded selector detents. A raw numeric selector reading is not necessarily the printed panel setting: use the documented mapping before declaring a mismatch. Report unresolved inconsistencies without repeatedly cycling a functioning selector. Record each verified item with `737-checklist` while flight is stable.
- Choose the authorized intercept altitude from the chart and clearance, not an arbitrary round-number floor. Before leaving altitude hold, verify the descent mode, selected altitude, and selected rate; mode activation can synchronize targets, so read them again afterward. Recheck actual descent and IAS. If descent prevents deceleration, revise the rate or level safely within procedure limits and configure at the documented speeds; do not chase a lower altitude while fast and unconfigured. Continue with `737-approach`.
