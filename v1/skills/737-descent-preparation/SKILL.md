# Descent preparation

1. Read the selected chart and current weather. Establish runway, navigation identifiers, frequency, inbound course, altitude restrictions, distance reference, minimums and missed-approach requirements. Do not substitute ILS DME or distance to threshold for a chart's VOR DME reference.
2. Verify pressurization landing altitude and perform system-annunciator recall followed by a fresh panel read. Inspect and address indicated electrical, flight-control or other configuration faults using the applicable procedure.
3. Obtain landing flap/VREF data for actual weight from APPROACH REF or an approved performance source. If the FMC displays blank speeds or weight, resolve the missing data rather than guessing VREF. Confirm entries in the accepted FLAP/SPD field, not merely in the scratchpad; read and resolve CDU messages.
4. Set assigned QNH and verify local/standard mode on the required instruments. For BARO minimums, enter the chart's decision altitude in feet AMSL, not the parenthesized height above threshold. Use radio decision height only when that reference is authorized; terrain AGL is not interchangeable with threshold height. Read back minimums mode and value on both sides; check that BARO decision altitude exceeds threshold elevation by the published height. If the interface cannot enter or expose the required setting, report the limitation and leave the item unverified; never substitute threshold height or mark the blocked setting complete.
5. Select the applicable minima row only after checking visibility and missed-approach climb capability. Brief the continuation decision and missed approach; dual-channel autoland does not authorize lower minima.
6. Choose the landing automation strategy before tuning. Dual-channel ILS autoland requires both NAV receivers on the same published ILS frequency, both identifiers verified and both courses set inbound; an ILS on one receiver and a VOR on the other is not an autoland setup. If the chart also requires VOR DME, resolve an approved distance source or a different authorized approach strategy before intercept; do not silently substitute ILS DME. Select and verify an appropriate autobrake setting for runway conditions. Complete the descent checklist from these observations before intercept workload increases.
